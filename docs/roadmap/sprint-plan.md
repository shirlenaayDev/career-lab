## 1. Ringkasan

Dokumen ini mendefinisikan struktur pekerjaan (Work Breakdown Structure) proyek Career Lab dari tahap Discovery hingga Web Application, serta tools yang digunakan pada setiap tahap.

WBS disusun dalam 2 level:

1. **Sprint** — fase besar proyek
2. **Deliverable** — dokumen/artefak konkret yang menandai sprint tersebut selesai

Detail pekerjaan pada level task individual didokumentasikan sebagai checklist pada masing-masing GitHub Issue, bukan pada dokumen ini.

## 2. Work Breakdown Structure

| 7 | Portfolio & Web Application | Backend, dashboard, case study | VS Code, Laravel |
| 8 | Internship Preparation | Interview story, application tracker | Notion / repository |

---

## 3. Tracking & Tools

Proyek ini menggunakan **GitHub** sebagai single source of truth dan **GitHub Projects** sebagai alat pelacakan progres:

| Elemen WBS | Representasi di GitHub |
|---|---|
| Sprint | Milestone |
| Deliverable | Issue |
| Task individual | Checklist di dalam Issue |
| Status pengerjaan | Board (To Do / In Progress / Done) |

Sprint dianggap selesai apabila seluruh Issue pada Milestone terkait berstatus closed.
